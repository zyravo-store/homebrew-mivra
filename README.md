# Mivra Homebrew Tap

Install [Mivra](https://mivra.zyravo.store) on Apple Silicon or Intel macOS with Homebrew:

```sh
brew install --cask zyravo-store/mivra/mivra
```

Packages are signed, notarized and verified. Apple Silicon uses the arm64 DMG; Intel uses the Universal DMG. Downloads and matching SHA-256 values come from the [public release](https://github.com/zyravo-store/mivra/releases/tag/v1.0.1).

A normal uninstall preserves local user data. Review the explicit `--zap` operation before removing application data.
